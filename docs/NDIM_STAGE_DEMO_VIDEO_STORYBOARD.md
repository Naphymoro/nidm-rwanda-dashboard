# NDIM Engine Stage Demo Video Storyboard

This file is a screen-recording script for creating short demo videos for testers. Each clip should be recorded from a fresh local NDIM Engine session and saved as `stage-01-intake.mp4`, `stage-02-sdmx.mp4`, and so on.

## Recording Setup

1. Open NDIM Engine locally.
2. Use a clean test workspace or duplicate `ClimateTales Rwanda`.
3. Keep the browser zoom at 100%.
4. Use the stress-test corpus files only when a stage needs realistic evidence.
5. Narrate what the user should see, why it matters scientifically, and what the next stage consumes.

## Stage 1: Narrative Intake

Show the workspace selection, evidence route selector, input method selector, and file/manual entry area. Explain that the tool does not silently load sample stories; all narratives must be uploaded, pasted, or typed by the user.

Key narration: "This stage turns field stories, interviews, focus groups, indigenous knowledge, citizen reports, and social feed excerpts into governed observations with source, place, consent, visibility, and route metadata."

## Stage 2: SDMX Gate

Show readiness checks, validation fields, approval queue, Approve, Reject, and Commit reviewed records.

Key narration: "The SDMX gate ensures stories become comparable records. Approved and rejected records are committed into separate repositories, with hashes and reviewer context preserved."

## Stage 3: Repository

Open the repository view and full repository tab. Show accepted, rejected, active review, and waiting-commit sections.

Key narration: "The repository is not just storage. It is the evidence ledger. Encoder outputs are appended back as manual, AI, and hybrid columns so modelling remains traceable to the story."

## Stage 4: Encoding

Demonstrate manual scoring one story at a time. Then switch to AI encoder for the same story, then hybrid encoder. Show comparison blocks.

Key narration: "Encoding converts each story into six auditable variables: exposure, credibility, trust, inoculation potential, barrier pressure, and social influence. Manual, AI, and hybrid outputs can be compared before modelling."

## Stage 5: Compartmental Model

Run the S/M/T/I/R model. Show equations, adoption curve, uncertainty band, and the explanation of how Stage 4 inputs feed the equations.

Key narration: "The encoded narrative variables become model parameters. Trust and credibility push adoption-aligned flow; barriers slow it; inoculation potential moves people into resistance to misinformation."

## Stage 6: Agent-Based Model

Run the household model. Show peer effects, media effects, and ODE versus agent comparison.

Key narration: "This checks whether local household heterogeneity or peer networks change the aggregate story."

## Stage 7: Digital Twin

Enter observed adoption, trust shift, and barrier shift. Rerun the twin.

Key narration: "The twin compares prediction with observed feedback, reruns the hybrid model, and passes the updated signal into uncertainty and policy stages."

## Stage 8: Bayesian Update

Show prior settings and posterior output.

Key narration: "A prior is the model's starting belief. A posterior is the updated belief after accepted evidence and feedback. It is not truth; it is transparent uncertainty."

## Stage 9: RL Optimizer

Run the optimizer and show best action, reward trajectory, and interpretation.

Key narration: "The optimizer stress-tests policy packages. It supports decision-making but does not replace human review."

## Stage 10: Regional Analysis

Explain that this stage is optional. Run it only when evidence spans places or when a district-specific decision is needed.

Key narration: "If skipped, the final brief remains pooled. If run, the policy output can compare local barriers and trust signals."

## Stage 11: Knowledge Graph

Build the graph and show linked places, stories, themes, and interventions.

Key narration: "The graph helps researchers see which local stories share themes or intervention signals."

## Stage 12: Inoculation Lab

Generate inoculation drafts and show how the narrative vaccine can feed the digital twin.

Key narration: "The lab creates pre-bunking and refutational messages, then tests how they may change adoption predictions."

## Stage 13: Policy Output

Run the full policy pipeline. Download HTML, open PDF view, and download JSON audit.

Key narration: "The primary output is a human-readable decision brief with confidence level, evidence grade, assumptions, limitations, and required human review."
