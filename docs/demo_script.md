# NIDM Demo Script

## Goal
Show how NIDM converts adoption data and narratives into modeled scenarios, uncertainty-aware outputs, and recommended programme actions.

## Flow
1. Open `/analysis`.
2. Explain that the current values are synthetic demo data until field data collection is complete.
3. Click **Run full analysis**.
4. Review the scenario comparison chart.
5. Review Bayesian parameter estimates and credible bands.
6. Review optimized allocation.
7. Review the mapped action package.
8. Click **Run multi-country demo** to show Rwanda, Kenya, and Nigeria comparison.
9. Click **Export PDF report** for a decision memo.

## Main Talking Points
- The platform is ready for real data.
- The current numbers are illustrative.
- The model supports Bayesian inference, optimization, country comparison, and report export.
- Field data will replace synthetic series when available.

## Caveats
- Do not treat demo numbers as operational recommendations.
- Calibrate policy intensity values against real costs before field use.
- Validate assumptions with domain experts.
