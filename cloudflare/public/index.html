Evidence-to-policy workflow

What the tool is meant to do

01

Ingest

Bring in interviews, open stories, focus groups, indigenous knowledge, citizen science reports, or social feeds.

02

Govern

Check source, consent, place, period, reviewer status, visibility, and SDMX-compatible metadata.

03

Encode

Score narrative meaning, misinformation risk, trust, barriers, social influence, and inoculation opportunity.

04

Model

Run compartmental and agent-based simulations to understand possible adoption pathways.

05

Learn

Use evidence feedback, Bayesian updating, and optimization to improve the decision picture.

06

Export

Generate readable policy briefs with confidence levels, limitations, assumptions, and human review.

For ordinary users

Use the web interface first.

The public web app should become the default way for non-technical testers to learn the process, prepare evidence, and review outputs. No terminal should be needed.

For advanced users

Run heavy modelling separately.

Larger Python modelling jobs can run through the local desktop app, Cloud Run, or Colab while the public web layer remains affordable and easy to access.
