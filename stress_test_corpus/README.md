# NDIM Synthetic Narrative Stress-Test Corpus

These files contain synthetic Rwanda clean-cooking narratives for stress-testing the NDIM Engine.
They are not real interview data and contain no real personal data.

Each CSV has 10 route-specific cases. Structured interview rows include Q1-Q5 fields, so the normal intake workflow can split each row into multiple governed narrative observations after upload.

Files:
- `ndim_stress_structured_interview_rwanda.csv`
- `ndim_stress_open_story_rwanda.csv`
- `ndim_stress_indigenous_knowledge_rwanda.csv`
- `ndim_stress_citizen_science_rwanda.csv`
- `ndim_stress_crowdsourced_batch_rwanda.csv`
- `ndim_stress_experimental_feed_rwanda.csv`
- `ndim_stress_bonus_open_story_kamegeri.txt`
